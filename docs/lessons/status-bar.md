# 输入框上方的状态栏

## 状态栏固定三行，小块按宽度收成「+N」

- 规则：输入框上方固定计划 / 子对话 / 子任务三行，每行 `flex-nowrap` + `min-w-0`、只占一行，没有内容的行不占位置；关闭子对话的按钮跟子对话那一行右端，不单独占一行。
- 规则：子对话小块（`w-56`）按中间容器实测的宽度决定显示几个（回调 ref + `ResizeObserver`，节点挂上再量），放不下的收成「+N」、紧跟最后一块，N 是实际隐藏数，窗口宽窄变化时跟着变；卡片、间距和「+N」的预留宽度都按根字号（rem）算，设置里改字号也准；不写死个数，也不 `flex-wrap`。
- 规则：卡片容器至少留 2.5rem（`min-w-10`）给「+N」：它是 `flex-1`（basis 0），窄屏下「请你选择」占满行时会被挤成 0 宽，里面的数字被 `overflow-hidden` 整个裁掉；断言要量容器和「+N」的实际矩形，只读 `textContent` 抓不到不可见。
- 起因：用户要求「后面的子对话只能一行展示，展示不下就用数字代表还有几个」，计划、子对话、子任务分三行。
- 防线：`scripts/ui/02-task.mjs` 的「状态栏-计划子任务子对话」。

## 计划的用时和等待跟着真实事件走，不跟着 Agent 改状态的时刻

- 规则：步骤的开始、结束取真实时间：挂上子对话的从子对话创建算起、合回时停；Agent 一次把几步直接标完成，按顺序摊开上次记时间到现在这段，不记成 0 秒。等不等子对话由面板对齐（`shared/plan.ts` 的 `linkKids`：步骤里写了子对话 id 缩写、标题和它一致，或写成等待中并提到它的标题就挂等待，规则见 [plan.md](./plan.md)「按标题对应时不按包含关系猜」），set_plan、收尾、子对话上报都跑一遍，不靠 Agent 记得带 step。
- 规则：计划窗口步骤下那行小字只用 `itemLine` 的结果，它已经带上备注，不要再接一次 `note`。
- 起因：用户截图里已完成的步骤 0s、四个等待步骤都是同一个 9m25s、备注重复两遍，子对话合回后步骤还挂着等待。
- 防线：`shared/plan.test.ts` 的摊时间、自动挂等待、换计划带等待三条。

## 输入框上方保持三行：计划、子任务、子对话

- 规则：输入框上方固定三行轻量状态栏（`data-status-row` 为 plan / helpers / children），计划是一小段字加细进度条（`w-fit`，不撑满成浅底条）；不因为运行区或页签里也有就删掉子任务、子对话两行。计划弹窗可以按设计改，折叠行不动。
- 起因：5b72252 删了子任务、子对话栏，dc23450 把计划改成整条浅底，用户要求「输入框的计划和子任务恢复到原来的样式和布局」。
