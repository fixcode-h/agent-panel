# 审阅弹窗和诊断报告

## 「默认不收起来」这类有两种读法的界面要求，按字面做

- 规则：用户说「X 默认不收起来」「默认不显示」这类话，先按字面理解成「要默认展开 / 默认不显示」去改，不要读成对现状的抱怨再反着改；拿不准时在回复第一句写清选了哪种读法。
- 起因：用户 2026-11-12 说「诊断报告标注默认不收起来」，9f6619d 理解成「现在不收起、要收起」，把论证这一步也改成默认收起；用户 2026-11-13 纠正为要默认展开。
- 防线：`scripts/ui/02b-subagent.mjs` 断言诊断报告的标注栏默认展开。
