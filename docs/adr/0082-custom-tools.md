# ADR 0082：自建工具（/createtool）

状态：已接受 · 2026-11-25

## 背景

用户 2026-11-25 提：项目里有一批反复要跑的命令（导表、Lua 编译、打包），每次都要 Agent 重新读文档、自己拼命令，拼错了还要再来。希望有个命令让 Agent 自己读文档和脚本，把它总结成一个带中文名、说明、什么时候用、参数的工具，以后所有对话的 Agent 都知道、能直接调；做好后由用户选存到项目（放文档目录、团队共用）还是全局。设计稿：`docs/openspec/changes/custom-tools/design.md`。

## 决策

- **一个工具 = 一条命令（或一段脚本）+ 参数定义 + 中文说明**（`shared/custom-tools/schema.ts`）。项目的存 `文档根/AgentPanel/Tools/<id>.json`，走项目数据（ADR 0078，P4 先签出）；全局的存 `<数据目录>/tools/<id>.json`。项目里同 id 的盖住全局的。存一版版本 +1，最多留 5 个旧版本。
- **Agent 只有一个入口**：面板工具 `custom_tool`（list / show / run / test / save），不把每个自建工具各做成一个 MCP 工具（ADR 0067 的个数和长度上限，各 CLI 延迟加载的做法也不同）。提示词里只加一行清单（最多 8 个、600 字，按最近用过的排）。
- **命令由面板展开，不让模型拼**：参数按定义校验（未知参数报错、类型、选项、范围、路径不出项目），值按当前 shell 加引号，cmd 里带 `"` `%` 的值、任何换行直接拒绝；展开后的命令照样过命令守卫。
- **授权**：已保存的工具默认不弹卡，Agent 调用直接跑（用户 2026-11-26：工具是用户自己存下、看过的命令，和普通工具调用一样）；工具设了 `confirm: true`（管理页「影响和输出」→「运行前先问我」）才弹授权卡，Agent 刚拼、还没保存的草稿试跑（不是只读的）照旧弹卡。「本对话不再询问」按授权类型 `ctool`（同一个工具，项目和全局分开算）。人在管理页点的试运行不弹卡。
- **长任务**：限时超过两分钟的（或标了总是后台的）交给后台命令，跑完推回，不让 Agent 轮询；结果只回退出码、按报错正则挑出的报错、输出最后几行和日志路径。
- **保存由用户点**：`save` 在对话里弹保存弹窗（请求 purpose `custom-tool`），显示草稿、试跑结果、重复检测（同 id、名字像、命令去掉参数后一样、同一段脚本），用户选项目 / 全局、能直接改名字和说明，或写意见让 Agent 再改；点完工具调用才返回。
- **管理**：「技能与 MCP」页加「工具」页签，编辑、试运行、复制 / 移到另一边、删除；「/」菜单多一组「自建工具」，选中后展开成让 Agent 用 `custom_tool` 跑它（出错了它能接着处理）。
- 同时补了内置命令 `/build` `/run` `/merge` `/pr` `/refactor` `/perf` `/deps` `/changelog` `/doctor`（都是展开成要求，面板不另写执行逻辑）。

## 影响

- 工具的 `capability` 字段先只是标记：等能力路由（ADR 0081）做「改动生效」时，把项目的编译、热重载工具当成一条路。
- 「依据的文件改了提示复核」「对话里命令卡片存成工具」「经验里的命令指向已有工具」放到二期。
- 演示版的保存、运行用 shared 里同一份校验和展开，命令不真的执行。
