# ADR 0014：AI 分析统一归属、统一用「分析」角色、统一窗口

状态：已接受 · 2026-10-25

## 背景

用户 2026-10-25 提出：所有 AI 分析要找到它的归属。子对话、子任务的分析都在父对话下开一个子对话来做（分析对象本身是子对话时，开在它的父对话下：子对话不能再开子对话，只能开子任务）；项目设置的分析在当前项目里开一个对话；放不进项目的统一放到 Chat 模式的对话。分析对话统一用一个分析角色（做成必备角色），AI 分析窗口也统一。

## 事实核对（改动前）

| 入口                               | 改动前                                                             |
| ---------------------------------- | ------------------------------------------------------------------ |
| 对话「更多操作 → AI 分析执行结果」 | 不管是不是子对话，都在项目里开一个顶层对话，用默认角色，跳页面过去 |
| 子任务窗口「AI 分析」              | 同上（2026-10-25 刚加）                                            |
| 工作流详情「分析执行」（最近几次） | 同上                                                               |
| 报错旁的「AI 处理」、内存分析      | 一律开 Chat 对话（项目设置里 Skill / MCP 的排查也是），不用角色    |
| 项目设置「AI 初始化项目」          | 后台跑一次 CLI（`/assist` 任务），过程只在 AI 窗口里，不留对话     |
| 窗口                               | 「AI 处理」一个大窗口；执行分析是小弹窗 + 跳转；初始化是 AI 窗口   |

## 决策

1. **归属只有一份规则**：`shared/analysis-home.ts` 的 `analysisHome(scope, root)`。
   - `task`（对话、子对话或它名下的子任务）：开成所在那棵树的顶层对话的子对话。顶层对话必须是项目里的直接对话（不是工作流执行、不是导入的只读记录），否则退回项目对话。
   - `project`：项目里的顶层对话。几次工作流执行的分析、导入的只读记录、项目设置里的排查、已有项目的 AI 初始化都在这里。
   - `chat`：面板设置、CLI、本机环境、面板内存这类和项目无关的，开 Chat 模式的对话。
     服务端本来就拒绝「子对话再开子对话」，这条底线不靠前端守。
2. **必备角色「分析」**（`builtin:analyzer`，第 8 个必备角色）：默认只读，只有提示词明确要求动手（AI 处理、AI 初始化写文档）时才做那一件事；不能开子对话、派子任务。所有分析对话的 `agentId` 都取它（`analyzerId`），没装上时退回不用角色。
3. **统一窗口**：`web/src/lib/ai-window.ts` + `components/ai-window/AiWindow.tsx`。所有入口只调 `openAiWindow`（AI 处理经 `openAiFix`，执行 / 子任务分析经 `AnalyzeDialog`，初始化经 `runAssistInProject`），对话用 `createAnalysisTask` 按归属建好；窗口里就是那个对话，可最小化、可接着问，「在父对话里打开 / 在项目对话里打开 / 在聊天里打开」跳到它所在的位置。分析结果里「开子对话去修」开在同一个父对话下。
4. **已有项目的 AI 初始化**改成项目对话：`/assist/prompt` 给第一句话，对话结束后 `/assist/resolve` 把最后一条回复解析成推荐，格式不对时让对话自己修正一次；设置开着就填进草稿，关着就把推荐记进项目。新建项目还没保存时没有项目可放对话，仍走原来的 AI 窗口。

## 不做

- 「AI 创建 / 优化」角色、工作流、Skill、命令、MCP 和「AI 配置参数 / 测试步骤」：它们是生成配置的助手，产出直接填进表单，不是分析，仍用 `AssistDialog`。
- UI 设计里的「AI 分析」：结果就在设计对话里，已经有归属。

## 影响

- 分析对话作为子对话时，父对话在它跑完前算「在运行」（ADR 0012），停止父对话会一起停掉它。
- 分析子对话结束时照常上报父对话（进收件箱，不叫醒父对话）。
