# ADR 0077：插件仿制的基础组件收回面板共用

状态：已接受 · 2026-11-23

## 背景

「可统一能力盘点」第 3 项：UE 插件早期不能 import 面板源码，自己写了一套基础组件（右键菜单、树、搜索框、问号提示、加载遮罩……约 2100 行）。插件接口 4 起插件已经能直接用面板开放的模块，这些仿制件却还留着：面板改了交互插件不跟，「设置 → 组件」调不到，GM 页漏挂菜单宿主右键没反应（2026-11-22）。UE 的菜单已经有子菜单和菜单内搜索，比面板的新。

## 决策

1. 以 UE 的实现为准搬进面板 `web/src/components/ui/`，去掉插件前缀、换成面板的 `cn` / `t` / `toast` / `copyText`，全部开放给插件：
   - `item-menu`（+ `item-menu-rows`）：按项目列表打开的菜单 `openMenu(e, items)` / `openMenuAt(el, items)`，子菜单、菜单内搜索、键盘。面板在 `App.tsx` 挂一个 `MenuHost`，页面和插件不再各自挂。
   - `tree/tree-list`（只画可见行的树）、`tree/tree-search`（树上的搜索、只留命中和上级）、`tree/caret`。
   - `search-box`、`loading-mask`；`help-tip` 用面板原有的那份（点问号不再冒泡到所在行）。
   - `split-pane`：按 CSS 变量分的多栏（百分比默认、窄屏上下排、拖边记住尺寸），存在和 `resize.tsx` 同一个 `pane:` 前缀下，读到 UE 以前的 `ue:pane:` 时搬过来。和 `resize.tsx`（按像素算宽度的面板栏）是两种布局模型，都保留。
2. 「设置 → 组件」的「弹层」组加这几件的示例，插件那边的示例删掉。
3. UE 插件 76 处菜单、31 处分栏、20 多处树和搜索框改成 import 面板模块，删掉插件里的副本。

候选方案：

- **改用面板原有的 Radix 菜单（`ui/menu`）**：不做。Radix 菜单是声明式的触发器 + 内容，UE 七十多处是「右键时按当前行拼一个项目列表」的用法，改成声明式要每处重写；两种用法都保留，列表式的就是 `item-menu`。
- **UE 的分栏直接换成面板 `resize`**：不做。两边的模型不同（UE 用 CSS 变量和百分比默认值、窄屏上下排），31 个页面要逐个改布局；把 UE 那份收进面板成 `split-pane`，两种模型各管一类页面。

## 影响

- 插件要右键菜单、树、搜索框、问号、加载遮罩一律用面板这几件，不再自己写（AGENTS.md「先找能共用的」）。
- 面板自己的页面以后要「按列表弹菜单」也用 `item-menu`。
