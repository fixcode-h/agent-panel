# ADR 0016：分析报告画在右侧功能面板，单项修复在当前分析对话里做

状态：已接受 · 2026-10-25

## 背景

用户 2026-10-25 提出：分析最后必须给出分析报告；分析页面的「提问」默认不勾选；项目分析（AI 初始化项目）结果出来后要有右侧的设置应用面板（参照老版本 AI 窗口右边的预览）；看看还有哪些分析也需要右侧功能面板；分析报告原来是固定在输入框上方的折叠卡片，可以单独修复某一项，这个挪到右侧功能面板、不在对话区显示，点修复就在当前分析对话里直接修；AI 分析对话的标题要和其他对话明显区分。

## 事实核对（改动前）

| 项                  | 改动前                                                                                     |
| ------------------- | ------------------------------------------------------------------------------------------ |
| 执行分析的结果      | `EvolutionCard` 固定在输入框上方，发新内容就收起；「修复」「写进源代码」各开一个子对话去做 |
| 教训评审的结果      | `LessonReviewCard` 同样固定在输入框上方                                                    |
| AI 初始化项目的结果 | 对话里只有一大段 JSON，结果交回项目设置的「AI 初始化」页才能应用                           |
| 分析对话的「提问」  | 开成子对话时跟父对话的开关，AI 排查固定打开                                                |
| 分析对话在列表里    | 和普通对话一样，只能靠标题文字认                                                           |

## 决策

1. **报告是分析的终点**：必备角色「分析」的说明里写死「最后必须给出分析报告」：提示词规定了结构化结果（`workflow-evolution`、`lesson-review`、JSON 代码块）时那个代码块就是报告；没规定时最后一节写「## 分析报告」。
2. **右侧功能面板**：`web/src/components/tasks/AnalysisPanel.tsx`。哪条回复是报告、是哪种由 `web/src/lib/analysis-report.ts` 的 `findReport` 判定（正在回复时只看最后一条用户消息之前的）。需要面板的分析有三种：
   - `run`（执行、子任务、几次工作流执行的分析）：代码问题按模块分组、角色和工作流的优化可看差异再应用，每段能折叠；
   - `lessons`（教训评审）：逐条应用；
   - `init`（AI 初始化项目）：写入的文件和推荐设置，按设置页分组逐项 / 整组 / 全部应用，直接保存进项目（对话旁没有设置草稿可填），推荐也记进 `initResult`。
     AI 排查（`fix`）不需要：它本来就在对话里动手处理，没有逐项采纳的东西。
     宽屏占对话右栏（和子对话、运行、文件同一栏，同一时间只显示一个；默认开、收起按对话记在 `task-report:<id>`），窄屏和放在父对话右栏里时从标题栏按钮盖在对话上打开。对话区不再显示报告块（结构化块本来就被 `stripEvolution` / `stripLessonReview` 去掉，初始化的 JSON 由 `stripInitJson` 去掉）。
3. **单项修复在当前分析对话里做**：面板上的「修复」「写进源代码」在这个对话里发一条以 `【修复】<标题>` 开头的消息，明确要求只动手做这一项（分析角色说明里的例外）；按这条消息认出这一项「处理中 / 已处理」（`fixState`）。不再开子对话。
4. **分析对话带种类**：`Task.analysis`（`run` / `init` / `lessons` / `fix`，`createAnalysisTask` 必填），子对话列表也带出来；旧对话按是不是用的必备角色「分析」认。侧栏、项目首页、子对话栏和标题栏在标题前放 `AnalysisMark`（强调色标签：分析 / 排查 / 评审 / 初始化）。
5. **「提问」默认不勾选**：`createAnalysisTask` 一律按调用方给的、默认关，不再跟父对话的开关；AI 排查也不再固定打开，要问在对话里打开。

## 不做

- 不给 AI 排查加右侧面板：它的结论就是处理结果本身。
- 不在功能面板里做初始化的「重新初始化」：重跑仍从项目设置发起。

## 影响

- 点修复后分析对话会改文件：它在项目目录里跑，改动出现在这个对话的「更改」里。
- 分析对话不再挂出修复用的子对话，父对话下少了这类子对话。
