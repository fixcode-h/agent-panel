## 2. 打开地图：发生了什么、做了什么

**经过（归档节点 06:15–06:24）**

1. 编辑器开着家装地图 `Dun_HomeDecoraionS_02_P`；Agent `pie_start` 后 `ue_lua` 找 `ClinkGlasses` 子模块，取不到。读了 4 段 Lua、跑了 4 次 `ue_lua exec` 才弄清：当前主模块是 HomeDecoration，碰杯挂在 BigWorld 下，**要换 BigWorld 的地图**。
2. 先试 `SwitchMainModule` 在 PIE 里硬切主模块，报错（邮件子系统 nil），放弃。
3. `ue_console open /Game/Maps/WC/QuestMain/QuestMain_P_Free`：弹「危险命令」卡 → 用户允许 → 工具**立刻回 ok**，地图没变。随后 `ue_status`、`ue_log`、`sleep 12`、`ue_status`、`ue_log`、`ue_screenshot`（「这个世界没有视口」）、`ue_status`，34 秒后地图才变——同一时刻用户发来「换地图了」。
4. 收尾还原地图又来一遍：`open` → 危险命令卡 → `sleep 10` → `ue_status` → `ue_log` → `sleep 15` → `ue_status`，Agent 最后写「还原命令已发出但地图仍显示 QuestMain，可能有保存确认阻塞」。
5. 另外 `pie_start` 也是马上返回：Agent 起完 PIE 立刻查 Lua，或 `sleep 18` 再查，拿到的都是半初始化的状态。

**原因**：编辑器世界里的控制台 `open` 是「旅行请求」，命令本身立即成功，真正换没换、会不会弹「保存改动」对话框都不回报；面板也没有「打开地图」这个动作，Agent 只能 sleep + 轮询。

**已做（等合 main 发版）**

| 位置                                      | 改动                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| UELink 2.22.0（UEKit PR #105，已合 main） | 新操作 `editor.map`：`status`（当前地图、PIE、没保存的关卡包、上一次打开的结果）/ `open`（按地图名 / 包名 / .umap 找地图，同名多张报候选；PIE 中拒绝；有没保存的关卡改动时拒绝并列出，或 `unsaved=discard` 丢掉；下一帧调 `FEditorFileUtils::LoadMap`，加载时压住模态对话框）。`pie` 开 PIE 可带 `map`（`GlobalMapOverride`，只在 PIE 里玩那张图，和 GameTest 的 `pie.start` 同一做法）。**云端没法编，需要本地用 5.4 / 5.8 编一次**      |
| UE 插件 0.63.0（agent-plugins PR #286）   | `ue_editor action=open_map`：PIE 在跑先停 → 没保存的关卡改动默认报错（`unsaved=save` 走保存和 P4 签出；`unsaved=discard` 弹确认卡，可「本对话不再询问」）→ 打开 → **等加载完才返回**，返回里带「测完怎么换回原图」。UELink 旧时退回控制台 `open` 并等编辑器世界的地图名变过去，超时说明可能卡在对话框。`pie_start` 可带 `map`，**等 PIE 世界起来才返回**。工具说明里写明「换地图不要用 ue_console open，也不要 sleep 后反复查 ue_status」 |

这次的场景按新工具是两步：`ue_editor pie_start map=QuestMain_P_Free`（编辑器的图不动、不用还原），失败了看 `ue_log`。
