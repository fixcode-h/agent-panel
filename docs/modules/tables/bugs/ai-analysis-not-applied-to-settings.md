# AI 分析表格风格的结果应用不到项目设置的表格设置里

- 状态：已修复（`shared/tables-assist.test.ts`、界面检查 `14-tables` 通过）
- 症状：项目设置 → 表格里点「AI 分析」，结果写进结构文件后，上面的「表头」「通用枚举」还是旧的；再点「保存表头」又把 AI 写的盖回去
- 入口：`web/src/components/tables/TablesAnalyze.tsx`、`web/src/components/projects/ProjectTablesHeader.tsx`
- 根因类型：同一份数据各组件各读一份副本，写完不通知别处，旧副本保存时整份覆盖
- 模块：`tables`
- 关键词：AI 分析、表格风格、表头、结构文件、通用枚举、覆盖、副本、localStorage

## 根因

「表头」「通用枚举」「校验」「AI 分析」和表格页各自在打开时读一次结构文件，存在自己的 state 里。AI 分析把结果写进结构文件后只更新了自己那份：「表头」区还显示打开时的内容（比如「每张表自动识别」），用户以为没应用上；点它的「保存表头」时用的是旧副本整份写回，AI 写进去的表头、分隔符被盖掉。另外结果只记在内存里，刷新页面就没了；AI 输出里有一个不认识的表头角色（default、export 这类）整份结果都校验失败。

## 修复

- 结构文件在页面里只留一份（`web/src/lib/table-schema.ts`），保存都先重读最新的再改，存好后所有用到的地方一起更新；设置表单的草稿没改过时跟着新内容走。
- AI 分析结果改成「应用到表格设置」，应用后上面的表头、通用枚举立刻变；还没应用的结果存在浏览器里，刷新后还在。
- 不认识的表头角色改成「其它」并把原词留作行名。
