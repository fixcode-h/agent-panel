# web · 流程图画布

[web 模块](README.md)的子页面：工作流编辑器和任务流程图视图：浮动面板、节点卡片。模块的状态块、入口、依赖和回归验证见 [README.md](README.md)，Bug 记录见 [bugs.md](bugs.md)。

2026-10-31 从 `README.md` 原样挪出（文字没改），各条的日期和结论以当时为准。

## 职责与实现

- 流程图画布：工作流编辑和任务流程图视图（`web/src/components/flow/`，基于 `@xyflow/react`）。
- 流程图编辑器的浮动面板（`web/src/components/flow/FlowEditor.tsx`，照 Workflow 设计稿）：左上「工作流 › 名称」+ 撤销 / 重做和流程切换，右上自动保存状态（工作流没有手动保存，不放假的「保存」按钮）和「在项目里运行」，底部「画布工具」条放平移模式、添加节点、自动排列、就绪检查（回到属性栏「流程」页并滚到就绪检查）、全屏、属性栏、运行。撤销历史在 `flow/history.ts`：只在内存里、按工作流 id 各一份、上限 100 步，记的是改动前的整份 `flows`，撤销后交给草稿照常自动保存；一次拖动（`FlowCanvas` 的 `onChange` 带 `move:` key，按下到松手同一个）合成一步，属性栏里焦点在输入框时 1 秒内的连续输入合成一步，按钮类改动各算一步。快捷键 Ctrl/⌘+Z、Ctrl/⌘+Shift+Z（或 Ctrl+Y），焦点在输入框或有弹窗、菜单时不抢。「在项目里运行」（`web/src/components/workflows/RunInProjectDialog.tsx`）选项目、写任务描述，先把没自动保存的改动存一次再 `POST /tasks`（mode = workflow，和项目输入框同一个接口），建好跳到任务页。画布窄时（容器查询）省掉「工作流 ›」、自动保存状态和小地图，工具条靠左，免得压住小地图。布局照 Workflow 设计稿：画布和属性栏是并排的两张圆角卡片（四周和中间 8px 缝，画布带一圈 `line` 细线），底部工具条 48px 高、按钮 36px；属性栏顶部一条页签写当前编辑的对象（「节点 · 名称」「流程 · 名称」「连线」「结束」），页签上的叉号收起属性栏，原来各面板里的大标题去掉；拖宽属性栏的拖动条在两张卡片之间的缝里（卡片的圆角裁切在内层，拖动条不被裁掉）。画板里的「保存」不做（自动保存）。底部工具条运行按钮后面是「重新运行」、项目下拉和「运行中」胶囊，属性栏页签条在当前对象后面多「流程说明」「运行进度」两页：数据都取全局任务列表（摘要，有任务在跑时 2.5 秒刷新），`flow/RunProgress.tsx` 的 `useFlowRuns` 按所选项目里用这个工作流的顶层对话筛（以最后一次运行记录的 `workflowId` 为准），「运行中」看 `runRunning`，点开最新那次；「重新运行」（`RunInProjectDialog.tsx` 的 `useRerun`）先取一次完整任务（摘要里的描述截到 500 字），照第一条用户消息的描述和附件、提问开关、独立分支、执行上限再 `POST /tasks`，没跑过就不显示；项目下拉默认上次新建任务用的项目（`last-project`），也作为「在项目里运行」弹窗的默认项目；「流程说明」直接用 `DocEditor` 编辑工作流的 `document`；「运行进度」列最近一次执行最后一次运行的主流程节点。节点属性栏的每一步照画板排：执行方式、「角色 / Agent」并排（节点上的步骤总是用默认 Agent 的档位模型跑，见 `nodeAgentRun`，所以 Agent 一格只读）、模型档位三段、要做的事，验收 / 最多验收 / 完成后确认 / 失败重试排成一张带分隔线的「步骤选项」列表。节点卡片宽度没照画板改成 190：自动排列列距和已保存坐标按 264 宽排的。回归：`scripts/ui/03-library.mjs` 的「工作流-撤销重做」「工作流-在项目里运行」「工作流-运行进度页签」「工作流-运行中」。
- 流程图节点卡片（`FlowCanvas.tsx` 的 `CardNode`）：多步节点在卡片里逐行列出步骤（最多 3 行 +「还有 n 步」，这时不显示说明块），运行视图里每一步带状态（引擎的单步记录 `<节点>/step/<步骤 id>`，按 `nodeId` 对上）；运行视图（`web/src/components/tasks/TaskFlow.tsx`）在底部一行右边写节点耗时（`stepDuration`，执行中每秒走）和 token（节点及所有子节点的输入 + 输出，`stepsTokens` / `tokenCount`），和挂载流程放同一行，旧流程图按原行距排的也不会叠在一起；编辑器里不显示。自动排列的行距 `shared/flow.ts` 的 `ROW` 因此从 150 调到 200。连线颜色用主题 token（完成 `--success`、运行中 `--run`，照设计稿和卡片细框同一深浅，按 `color-mix` 调浅），卡片上的状态胶囊在染了底的卡片上是白底 + 同色细框、白卡片上只留一圈 `line` 细线，执行者标签在染了底的卡片上加一圈细线；多步节点里正在跑的那一步序号反色成实心小胶囊；底部只有耗时和 token 时耗时靠左、token 靠右。箭头是自己画的 `<marker>`，id 按状态名加每张图的 `useId` 前缀生成（xyflow 自带箭头按颜色字符串生成 id，用不了 CSS 变量）。
