# 子对话说一句打算就收尾，一直停在等下一条消息

- 状态：已修复（e2e `04-subagents`「子对话计划做一半就收尾……」、`shared/task-idle-ask.test.ts` 通过）
- 症状：子对话回一句「现在启动全量界面检查（后台），同时跑 lint。」之类的打算就结束这一轮，没有调用任何工具；计划停在一半，子对话一直「等待下一条消息」，父对话那一步一直在等它
- 入口：`server/tasks.ts` 的 `settleChildTurn` / `settleChildWorktree` → `nudgePlan`；`shared/task.ts` 的 `planStalled`；`shared/engine.ts` 的「计划怎么维护」
- 根因类型：模型提前结束回合（CLI 正常报 result、没有工具调用），面板对「计划没做完就收尾」只上报父对话，没有自己的兜底
- 模块：`server`（`server/tasks.ts`、`shared/task.ts`、`shared/engine.ts`）
- 关键词：子对话、不执行、等待下一条消息、计划没做完、只说不做、提前结束回合、催办、deepseek

## 现象

同一个父对话下的几个子对话（Claude Code + `deepseek-v4.1-flash`）先后多次停住，每次都是同一个样子：

| 子对话                          | 最后一句                                                                                    | 计划 |
| ------------------------------- | ------------------------------------------------------------------------------------------- | ---- |
| 对话间消息不折进过程折叠        | 三处代码改完。先跑类型检查和 fold 单测。                                                    | 1/8  |
| 对话间消息不折进过程折叠        | 构建成功（3.8s）。现在启动全量界面检查（后台），同时跑 lint。                               | 4/8  |
| 修复 Claude Code 上下文用量为 0 | Chrome 在 `C:\…\chrome.exe`。我用它重跑全量界面检查（先重建 demo 产物），同时复跑快速检查。 | 4/8  |

## 根因

1. **模型提前结束了回合**：三次的思考里都已经想好下一步要调用什么（「先启动 ui-check 全量后台，再跑 lint」「执行。」），回复里也说了要去做，但这次回应里没有任何工具调用；Claude Code 照常报这一轮结束（result 成功）。排除过的面板侧原因：没有插话打断（其中两次前后没有任何送进来的消息）；子对话没有 `wait_user_message`（不是模型自己调了等待）；不在排队等 API 名额。
2. **面板没有兜底**：一轮结束时面板只把「未完成：计划还没做完」报给父对话。父对话在忙别的（回答用户、派新子对话）就没人推，子对话停在保活上一直等下一句。之前加的自动询问要等 3 分钟才问，用户看到的就是「一直在等待下一条消息」。

## 修复

- 子对话一轮正常结束（进程结束，或停在保活上等下一句）时，计划没做完、计划里没有在等结果的步骤、没有后台命令和待答提问、也不是只剩合回：面板等 2 秒（让 CLI 停到等待上）再核对一次，还停着就以面板的名义推它「接着做「下一步」，直接调用工具去做」。
- 同一个进度（计划 id + 已完成几步）只推一次；推过还原地不动就照常上报父对话「未完成」，不来回推。只剩「合回父对话的分支」时归「催它 submit_merge」那条提醒管。
- 「计划怎么维护」加一条：计划没做完、也没在等结果时不要结束这一轮，要做的事直接调用工具。
