# 收尾自检问过以后又接着查，说「派子对话」就停了，子对话没开出来

- 状态：已修复（`server/tasks/before-end.test.ts` 通过）
- 症状：没列计划的对话被结束前钩子问过「做完了吗」后，又读了两个文件，回复「我按 Bug 流程派子对话核实并修」就结束了这一轮，既没派子对话也没调用 end_turn，面板也没再拦
- 入口：`server/tasks/before-end.ts` 的 `decide`（没列计划那一档）
- 根因类型：问过以后只数问过之后的动作，接着做了一点（只读）也按「做的事少」放行
- 模块：`server`（`server/tasks/before-end.ts`）
- 关键词：收尾自检、结束前钩子、end_turn、派子对话、没开子对话、check:、small、只读

## 现象

用户导出的对话「丢弃本地所有改动前先确认工作区状态」（2026-11-05）：用户 16:13 报设置页「关于我与记忆」高亮错页签。对话读文件定位，16:14:58 只回了一句话要结束，钩子问了收尾自检；它又读了 `section-nav.tsx`、`section-nav.ts` 两个文件，16:15:11 回复「按 Bug 流程派子对话核实并修」（思考里也写了先 set_plan 再 create_conversation），但没调任何工具就结束了，16:15:21 这一轮收掉，子对话没开。

## 根因（证据链）

1. 第二次要结束时钩子放行 ← `decide` 没列计划那一档：`workSince` 问过以后从提醒那条之后数，只有 2 次只读，`acts + floor(reads / 3) < 3` 走 `allowEnd('small')`。
2. 「问过以后只回了话、没再动手的不再问」本意是防空转，但它问过以后又调了工具接着做，说明没把问题当成「做完了」回答，只是换了个地方停；也没用 end_turn 交代。
3. 一轮结束后的 `nudgeNoPlan` 看到这一轮钩子问过，按设计不再问。

## 修复

- 问过以后又调了工具（`w.checked && w.tools > 0`）、还是没用 end_turn 交代就要结束：再问一次（日志 why 记 `check-resumed`）。两次提问之间隔着真动作，不会空转；问过只回了话的照旧放行。
- 防线：`server/tasks/before-end.test.ts`「收尾自检问过以后又调工具接着做」（修之前放行，用例失败）。
