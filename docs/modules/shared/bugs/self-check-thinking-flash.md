# 对话结束时最后闪出一段思考过程，随后又被隐藏

- 状态：已修复（`shared/end-turn.test.ts` 通过）
- 症状：每次对话一轮结束，回复最后先出现一段思考过程（「用户只是打招呼，我已经回复完毕。现在需要调用 end_turn…」），几秒后又消失
- 入口：`shared/end-turn.ts` 的 `visibleMessages`
- 根因类型：隐藏规则只在 end_turn 到达后生效，之前正在流式输出的思考照常画出；上一个修复去掉了同一条里的「查询 MCP 工具」，这条消息就整条被藏掉，思考变成闪一下
- 模块：`shared`（`shared/end-turn.ts`）
- 关键词：收尾自检、思考过程、闪一下、end_turn、隐藏、结束前钩子、查询 MCP 工具、ToolSearch

## 现象

用户导出的对话「UnLua 项目协调与需求受理」（2026-11-22）：协调器回完「你好」没调 end_turn，结束前钩子发「（收尾自检）这次的事做完了吗？」，模型先想一句「需要调用 end_turn 收尾」，再调 end_turn 说一句收尾。界面上这段思考先显示，end_turn 到了后整条消息被隐藏。

## 根因（证据链）

1. `visibleMessages` 只在消息里出现 end_turn(done) 之后才把这条（文字和思考）藏掉 ← 流式输出时思考先到，这时还没有 end_turn，按普通消息画出思考。
2. 6acd936（PR #403）以前，这条消息里还有一次「查询 MCP 工具」，消息因为有这行工具一直留着、思考也跟着留着，所以看不出闪；修掉多余的查询后这条只剩 end_turn，整条藏掉，思考就成了闪一下。

## 修复

- `visibleMessages`：面板提醒（hook / nudge）之后、还没调工具也没写字、只有思考的那条先不画；调了别的工具或写了字照常显示（思考一起显示），调了 end_turn 就和原来一样整条藏掉。只看位置和工具，不看文字。
- 防线：`shared/end-turn.test.ts`「收尾自检之后只有思考的那条先不画」。
