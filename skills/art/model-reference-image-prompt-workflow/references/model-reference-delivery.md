# 建模参考图交付参考

这份参考用于确定视图组成、部件拆分、比例口径和验收标准，不替代具体项目的建模规范。没有项目规范时可以采用下列默认值，但要在最终结果中标记为默认值。

## 适用场景

- 用户给了参考图（照片、概念图、视频帧）和建模要求，需要一份建模师能直接照着执行的参考图提示词文档。
- 需要在 Blender/UE 里贴 reference plane 描形、按标注尺寸缩放对齐的作业底图。
- 需要把整体拆成可分别建模的部件，逐件给出尺寸与接口依据。
- 需要给材质师提供材质分区与配色依据，需要给评审提供体块与配色印象图。

不适用于：直接替代建模（本技能只产出参考图规格）、把带透视的照片当作可量取的比例依据、把生图结果当作可直接读数的工程图纸。

## 部件拆分

部件图的数量直接决定交付张数与建模工作量，拆分方案必须先和用户确认：

- **用户已指定**：按用户给出的部件数量和名称逐件出图，不增删、不改名；部件图数量等于用户给的部件数。
- **用户未指定**：先读参考图分析可见结构，推荐一套拆分方案再询问用户。划分依据按优先级：功能边界（车体、炮塔、火炮、行走机构）、是否运动件或可拆装件（舱盖、悬挂臂、负重轮、履带）、材质分区、单独建模成本。
- 推荐时给出 2–4 个可比较粒度而不是单一答案，并说明代价：粒度越细，部件图越多、单件尺寸表条目越多、总张数越多，但单件更好建模；粒度越粗，张数少但单件复杂度高。
- 至少覆盖：部件 ID、名称、拆分依据、是否运动件/可拆装件、单独成图的文件名、与相邻件的接口或装配标注。
- **用户明确答复前不得输出最终文档**：可以先给参考图解析结论和推荐拆分，但图片清单、部件图 prompt 和合计张数都依赖这份答复。
- 部件图与整体视图板的关系：整体板给整体比例尺、总尺寸和部件间关系；部件图给单件自身尺寸、接口位置和安装面。两者共用同一比例尺，便于在建模时互相对齐。

## 四类参考图各自能做什么

| 类型 | 用途 | 允许 | 禁止 |
| --- | --- | --- | --- |
| 正交视图板 | 贴 reference plane 描形、量比例、对齐中线 | 平涂分色、清晰轮廓、纯色背景、共用比例尺 | 透视、缩短、环境、投影阴影、地面、景深、纹理噪点 |
| 部件图 | 单件建模、接口与安装面判读 | 单件正交视图、局部尺寸标注、与整体一致的朝向 | 混入其它部件、丢失接口位置、与整体比例尺不一致 |
| 3/4 透视彩图 | 看体块关系、轮廓感觉、配色方案 | 材质、光照、旧化、背景氛围 | 被当作量比例依据 |
| 局部特写 | 细节部位的结构判读 | 干净构图、同一光照、与整体视图对应 | 遮挡关键结构、夸张艺术化 |
| 材质/配色板 | 材质分区、颜色、旧化程度参照 | 色块、材质球、区域标注 | 与几何视图混在一张图里交付 |

## 分图规则

一篇文档对应一组图片，每张图单独生成、单独交付，交付文档必须逐图列清单：

- 一张图只承担一种用途：正交视图板、部件图、3/4 透视彩图、局部特写、材质/配色板各自成图。
- 正交视图板是唯一允许把多个视角合并到一张图的类型，因为多视图必须共用比例尺和中线；合并时按宫格排布，并同时说明是否需要逐视图单独生成的源图。
- 部件图按拆分方案逐件一张，不合版：把多个部件拼到一张图会让建模师无法按单件描形和对齐接口。
- 局部特写按部位逐张：炮塔、悬挂、履带、舱盖、铰链各一张，不合版、不拼接。
- 材质/配色板不与几何视图合版，避免把材质噪声带进描形底图。
- 3/4 彩图不与其他视图合版，也不与正交视图同图。
- 清单字段：图号、文件名、参考类型、是否单独成图、内容与视图构成、像素与格式；末尾给出交付合计张数与“不单独成图的中间产物”（逐视图源图、候选图、拼版底稿）说明。
- 只写“若干张”“一组参考图”而不给清单，视为规格未完成。

## 视图定义

- 视图集合：正视图（front）、侧视图（side）、俯视图（top），载具类补背视图（rear）。
- 正交投影：平行光线投影，不带透视缩短；等距/45° 属于示意图，不能当比例依据。
- 宫格排布：正/侧/俯（或加背视）排成一张，共用同一比例尺、中线对齐、视图间距一致；也可以逐视图单独出图后拼版。
- 视图对应：左右侧视图必须互为对应、无遮挡；不可见面在文档中标注为结构性补全，不假装是观察结果。
- 3/4 视角：只用于体块、轮廓和配色，不参与量比例。
- 部件图：每个部件单独一张，用与整体视图板相同的投影方式和朝向，标注单件尺寸与接口位置。
- 局部特写：炮塔、悬挂、履带、舱盖、铰链、工具挂点等，逐项单独出图并注明对应位置。

## 单位与尺寸

- UE 口径：1 unit = 1 cm；总长 7.2 m 的载具在 UE 里是 720 unit，FBX 导入后的大小由标注尺寸决定。
- 建模师用法：把参考图作为 reference plane 贴入 Blender/UE 建模模式，按标注尺寸缩放到对齐，再照着描形。
- 整体尺寸表字段：总长、总宽、总高（不含天线等附件时注明）、离地间隙、轮距、炮塔座圈直径、关键附件尺寸。
- 部件尺寸表字段：单件长宽高、安装面位置与朝向、接口尺寸（轴径、孔距、座圈直径、履带节距）、与相邻件的相对位置。
- 单位统一（建议 cm），同时给出 UE unit 值；用户未提供的尺寸列为待确认，不凭印象填写。
- 标注样式：工程图式尺寸线（界线、尺寸线、箭头）加尺寸数字；模型渲染不可读数时改为后期叠加。

## 格式与分辨率

- 格式：PNG（推荐，无损、支持透明）或 TGA；生图模型通常只直接输出 PNG/JPEG，TGA 由后处理转换。
- 分辨率：每边 ≥2048，四宫格按单格有效像素核算，避免“整图 2048、单格只有 1024”。
- 背景：纯色（推荐中灰或高对比单色），无渐变、无纹理、无地面、无阴影，便于描线与扣色。
- 交付：文件名与版本可追溯，正交视图、部件图与彩图/特写分文件，不混版。
- 打包：全部图片按清单命名后可打包为一个压缩包交付（如 `<主体名>_建模参考图_<版本>.zip`），包内附提示词文档与清单；包内图片张数必须等于清单合计张数，中间产物不混进交付目录。

## 材质与配色清单

- 分区键名与项目材质清单一一对应（例如 rig-manifest.json 的 Armor / Hardware / Edges / Recess / Tracks），不另造命名。
- 每项记录：颜色、材质感（粗糙度/金属度倾向）、旧化程度、对应几何区域。
- 材质板与几何视图分开交付，避免把材质噪声带进描形底图。

## 真实装备路径

复刻真实装备时不手绘三视图：用 8 方向环绕照（每 45° 一张，同一焦距、距离、机位高度）+ 局部特写替代，交付的是拍摄清单、标注要求和尺寸核对表，不需要生图 prompt。若仍需生图，只用于补足照片拍不到的面，并标注为推断。

## 反模式

- 把带透视的照片比例直接写进图纸，或让模型自由“补齐”背面结构后当成观察结果。
- 用户没确认拆分方案就先输出文档，导致部件图张数、命名和建模计划全对不上。
- 用户已指定部件数，却按自己的判断增删部件或改名。
- 把多个部件合并到一张图，建模师无法逐件描形和核对接口。
- 一张图里同时要求正交轮廓和材质光照表现，结果既不能描形也不能配色。
- 让模型渲染精确尺寸数字与尺寸线，交付后无人核对，建模师按错误数字缩放。
- 四宫格四格各画各的，比例尺和中线互不对应。
- 用“精细、逼真、高级感”等空泛词代替投影方式、背景、光照和分辨率要求。
- 只给整图分辨率，不核算单格有效像素。

## 验证方式

- 规格自检：部件拆分是否已有用户明确答复并与图片清单行数一致；图片清单是否逐图写明用途与是否单独成图、合计张数是否等于清单行数；视图集合、投影方式、比例尺、中线规则、尺寸表来源、材质键名、文件格式与分辨率是否逐项写明；未确认项是否标待确认。
- 图片实测：准确像素与比例、单格有效像素、各视图是否共用比例尺、中线是否对齐、背景是否纯净、有无透视污染。
- 对照验收：与用户提供的参考图逐项比对可见面与部件清单；与整体和部件尺寸表逐项核对标注；部件图逐件核对接口位置与安装面。
- 缺图片或元数据时标“待验证”，不勾选通过；存在透视污染、比例尺不一致或尺寸数字错误时只能称为候选。
