# 参考复刻：从视频/图片参考到 Blender 场景的一比一流程

> 适用：用户给一段参考视频（演示动画/实拍）或一组参考图，要求「一比一复原场景与模型」。
> 核心：**先把参考变成可读、可核对的信息**（元数据 → 接触表 → 细节放大 → 部件清单），再进入分件工坊建模，最后用并排对照验收。

## 阶段 0：参考素材解析（不进 Blender 也能做）

```powershell
python scripts/reference_frames.py --info 参考.mp4
python scripts/reference_frames.py --sheet 参考.mp4 输出目录 --step 3 --tile 5x3 --width 640
python scripts/reference_frames.py --frames 参考.mp4 输出目录 --times "0,5,10,65"
python scripts/reference_frames.py --crop 帧.jpg 细节.jpg --box x,y,w,h --scale 3
```

- 先看 `--info`：分辨率/帧率/时长决定采样步长（85 s 视频 `--step 3` 约 30 张，两屏接触表扫完）。
- **接触表扫全局**：机位变化、场景元素、剧情节拍（本项目 85 s 里有巡场、多个环境、撞墙高潮）。
- **单帧放大查结构**：每处「看不清的细节」都裁切放大 3 倍单读（负重轮辐板形状、链板垫片、炮口制退器）。
- 逐个部件记「部件清单表」：形状/颜色/数量/位置，以及纹理图案、尺度、方向、材质分区、反射与旧化，注明图片/裁切来源，作为规格输入；不设置高模/低模档位。

### 读图纪律（配合体检工具有效）

- 图片**逐张读**才有视觉通道；一次多张会被当二进制跳过（技能 pitfalls 已收录）。
- 先接触表再单帧：10 张接触表能扫完的内容，不要用 100 张单帧堆。
- 放大裁切优先于「读了看不清」：低分辨率整帧里数轮辐是浪费。

## 阶段 1：规格先行（照 `templates/spec-template.md`）

- 尺寸锚点表：主体长宽高、轮径/轮距、炮管长度、场景尺度。
- 部件清单表：由阶段 0 的清单直接转写，**每件标参考来源**（哪帧、哪张裁切）。
- 动画节拍表：由接触表的时间轴得到（如 f0–45 待机、f211 撞击）。
- 明确「不做什么」：参考里不存在的细节不臆造（例如参考炮管无抽气装置就别加）。

## 阶段 2：分件工坊建模

按 `references/part-workshop.md`：拆件 → 单件构建/预览/精修 → 装配。

- 每件的验收标准先写清（参考件的形状特征逐条对照）。
- 高细节件（行走机构/履带/炮塔）优先做，因为它们决定「像不像」。

## 阶段 3：组装 + 整机体检 + 多视角

- `inspect_scene.py` 全项（ngon/相交/命名/scale/UV/预算）。
- `capture_views.py --focus 主体` 六视角 + EEVEE；动画另做 `--frames` 多帧。

## 阶段 4：对照验收（这一步别省）

```powershell
python scripts/reference_frames.py --pair 参考帧.jpg 渲染图.png 对照.jpg --width 420
python scripts/reference_frames.py --montage 帧1.png 帧2.png 帧3.png --out 对比表.jpg --tile 3x1
```

- 选**机位与内容最接近**的参考帧与渲染帧并排：撞墙瞬间对撞墙瞬间、侧写对侧写。
- 逐项核对：轮廓比例、部件有无、纹理图案/尺度/方向、颜色关系、材质反射、旧化与阴影方向；记录机位、光照、曝光和色彩管理差异，把模型/材质差异写成下一轮工坊任务。参考未显示的面只做结构检查，不写成外观已匹配。
- 对照图与结论进项目 `docs/`（现场记录），成熟结论回流技能 pitfalls。

## 常见坑（本流程实测）

- 参考视频不能直接读进 Blender 脚本；必须先用 `reference_frames.py` 转帧。
- 接触表尺寸过大（>2000 px 宽）在某些看图通道会失败；`--width 640`、5×3 一屏最稳。
- 对照帧要选「同类瞬间」：拿参考的远景帧对渲染的撞墙帧，什么也验收不出来。
- 参考里「看不清」的部件不要靠猜：再裁切放大一次，或换一帧从另一个机位看。
