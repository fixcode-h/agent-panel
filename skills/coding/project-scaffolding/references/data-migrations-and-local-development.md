# 数据迁移与本地开发

## 适用场景

数据库、消息基础设施、本地依赖、种子数据和 schema 迁移入口。

## 决策问题

本地环境只模拟必要依赖；生产语义关键的数据库、消息和存储优先使用相同产品或兼容测试环境，而非不等价内存替代。

## 强制约束

- Migration 独立可审查、可追踪，不在生产启动时盲目自动执行不可逆变更。
- 使用 Expand-Migrate-Contract，回填可暂停、恢复和对账。
- 种子数据确定、幂等，仅包含测试/开发数据。
- 本地配置无真实秘密，依赖版本固定。
- 清楚区分 schema 创建、数据回填和旧结构删除。

## 反模式

内存数据库通过即认为真实 SQL 正确；一键脚本静默删除数据；随机种子导致测试不复现；应用启动拥有无限 DDL 权限。

## 验证方式

空库升级、旧版本升级、中断恢复、回滚兼容、生产规模演练、迁移 SQL 与锁审查、数据 checksum。
