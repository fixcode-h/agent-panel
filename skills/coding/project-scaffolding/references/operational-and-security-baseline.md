# 运维与安全最低基线

## 适用场景

可部署应用、服务、Worker、插件与包含外部输入的工具。

## 强制约束

按实际部署模型提供：

- 结构化日志和版本/环境身份；
- readiness/liveness 分离（仅服务适用）；
- 指标与 trace 接入点；
- 超时、取消、重试和过载默认值；
- 优雅关闭；
- 默认拒绝、最小权限、输入验证和秘密注入；
- 依赖锁定、secret scan、SBOM/制品校验的 CI 接入点。

不得让健康检查产生副作用或把下游短暂失败全部等同于进程死亡。默认配置关闭 debug、样例端点和非必要端口。

## 反模式

硬编码秘密；日志记录 Token；所有异常返回内部堆栈；健康检查深度调用所有依赖造成雪崩；构建来自开发机且不可追溯。

## 验证方式

全新环境基线；无秘密启动失败；下游中断下 readiness/liveness 行为；shutdown 演练；制品篡改拒绝；遥测敏感信息扫描。
