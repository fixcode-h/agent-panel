# 启动、组合根与配置

## 适用场景

应用入口、依赖装配、配置加载、环境切换和启动检查。

## 决策问题

组合根负责创建依赖与生命周期，业务代码只声明需要的能力。配置分默认值、环境值、运行期动态值与秘密，并定义优先级和版本。

## 强制约束

- 集中装配；禁止业务层 Service Locator。
- 启动时校验必需配置和外部依赖契约。
- 秘密不写入仓库、示例、日志或镜像。
- 动态配置使用不可变快照和原子切换。
- 启动失败快速且错误可诊断；不要以静默默认值掩盖关键缺失。

## 反模式

模块导入即启动外部连接；任意位置读取环境变量；配置优先级不明确；生产凭据出现在样例；组合根包含业务规则。

## 验证方式

最小/缺失/非法配置测试；不同环境优先级；secret scan；重复启动/停止；错误配置不污染 last-known-good。
