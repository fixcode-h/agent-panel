# 资源生命周期与后台工作

## 适用场景

连接、文件、线程、任务、订阅、Timer、Worker、游戏 World/Scene 服务。

## 决策问题

为每个资源指定创建者、所有者、启动顺序、停止顺序、超时、失败与重启策略。

## 强制约束

- 初始化失败不发布半可用服务。
- 后台队列和并发必须有界。
- shutdown 停止接收、传播取消、排空/持久化、释放资源，并受总 deadline 限制。
- 订阅和句柄成对释放，清理幂等。
- 持久任务不依赖请求或 World 的短生命周期对象。

## 反模式

fire-and-forget；全局析构顺序假设；关闭时无限等待；后台异常被吞；任务持有已结束作用域；GC 代替 Dispose/解绑。

## 验证方式

启动中途失败；重复启动/停止；强制取消；滚动重启；队列未排空；资源计数和内存回基线；宿主生命周期 teardown。
