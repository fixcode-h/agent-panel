# Blender 模型与动画契约

这份参考把分件建模、模块装配和模型动画的共通约束写成可执行契约。它适用于水轮车、房屋建筑、机械道具、角色部件和其他需要独立拆分与运动控制的资产。

## 适用场景

- 需要根据图片或视频重建可拆分的建筑、机械或场景资产。
- 需要让水轮、门、风车、履带、炮塔或其他部件独立旋转、位移或循环播放。
- 需要把 Blender 文件交给其他人继续装配、修改、渲染或导出，而不是只交付一张静态图。

## 规格与参考边界

1. 先把参考图转成部件清单、尺寸锚点、构图锚点和验收条目；每个部件标注参考来源或“结构性补全”。
2. 单张图只证明可见面、相对比例和构图关系。背面、遮挡面和内部连接不能写成“一比一已验证”；必须在规格里标记为待确认或按结构逻辑补全。
3. 规格同时写清模块名称、局部坐标系、局部原点、旋转轴、父级、允许接触和禁止穿透。尺寸写入锚点或装配表，不靠物体 `Scale` 传递尺寸。
4. 几何细节、纹理、材质、颜色与风格以参考图片实际内容为依据，不设高模/低模档位；分段、平滑、倒角和贴图方式按部件逐项决定，面数不能证明还原质量。

## 模块与装配契约

- Collection 负责功能分组，`GRP_*` Empty 负责模块根控制；网格使用 `SM_*`，材质使用 `M_*`，动作使用 `A_*`，相机使用 `CAM_*`。
- 一个可拆装功能模块至少有一个可识别根 Empty。屋顶、墙面、水轮、引水槽、门窗、平台和装饰件应按功能拆分，不能只把整栋房屋放在一个 Mesh 中。
- 单件脚本只在自己的局部坐标系中生成几何；装配脚本只做实例化、位置、旋转和父级关系。用共享网格实例化重复件，避免复制出无意义的独立网格。
- 父级操作前刷新依赖图并保持世界变换；需要让父级缩放生效的动画子件不要设置会抵消父级的 `matrix_parent_inverse`。
- 装配完成后重新打开 `.blend`，逐个把模块根 Empty 平移约 15 m 再恢复，检查所有子件跟随、恢复位置、Collection 归属和根对象数量；该测试通过才算模块化可操作。

## 几何、材质与接触

- 每个网格都创建 UV 层、Principled BSDF 材质和同步的视口材质颜色；生成后统一重算法线并应用旋转/缩放变换。
- 圆柱或圆环端盖使用三角扇或显式三角化；倒角是否需要及其宽度依据参考边缘特征并按部件尺寸自适应，不能给薄板、辐条和螺栓套用统一宽度。
- 旋转嵌套件优先使用真正的环形几何并保留结构间隙，避免用实心圆柱把轮毂、辐条或轴承插进轮缘造成跨对象穿透。
- `inspect_scene.py --intersect-report` 使用世界坐标、三角化后的 BVH。报告中的相交对必须按允许接触表人工分类；结构性穿透要定位、修复并复查。

## 动画控制契约

- 刚体模块的关键帧打在模块根 Empty、轮心 Empty 或专用控制器上；网格对象保持 `scale = 1`，不要把同一模块的旋转拆散到多个网格上。
- 运动件在局部坐标中先确定原点和轴向：例如水轮轮心为原点、轮轴沿局部 Y。旋转前做局部轴验证，避免导入或装配后绕错轴。
- 每个动作使用独立且可读的 `A_*` Action；场景设置 30 fps（若需求指定其他帧率，记录原因）。循环动作的首尾姿态、位置和相位要一致；完整一圈的旋转按 `2π` 连续变化验证，不能只比较欧拉数值相等。
- 角色或复杂机械使用控制器/父级层级统一驱动；不要逐对象手工打重复关键帧。缩放动画放在 Empty 上，网格子件保持单位缩放以免体检误报。
- 有滚动或行进关系时使用有效接触半径：`位移 = 2π × r_eff × 圈数`，轮转、履带相位和主体位移使用同一速度源。

## 证据与验收顺序

1. 单件预览：检查轮廓、数量、孔洞、材质分区、局部原点和轴向。
2. 装配体检：运行 `inspect_scene.py`，复核命名、UV、法线、变换、三角预算和相交分类。
3. 静态多视角：Workbench 检查几何，EEVEE/Cycles 检查材质、灯光和阴影；至少 front/back/left/right/top/three-quarter/closeup。
4. 动画多帧：用 `capture_views.py --frames` 检查首帧、中帧、尾帧和关键动作帧；确认控制器跟随、循环相位、旋转轴、穿模和相机覆盖活动范围。
5. 重新打开文件做模块平移/恢复测试，并记录模块数量、根对象数量、Action 清单和体检报告路径。
6. 只有以上证据齐全，才可声称模型和动画完成。FBX/UE 导出还要单独经过用户授权、导出自检和 UE 导入核对。

## 反模式

- 把整栋建筑、水轮和所有装饰一次性写进一个 Mesh 或一个巨型脚本，导致无法单件预览和独立修改。
- 用物体 `Scale` 代替尺寸，用默认对象名或 `.001` 名称交付，导致装配和导出难以追踪。
- 只看主视角或静态首帧就声称比例、穿模和动画通过。
- 把所有 BVH 相交都当成错误，或把有意接触当成“可以忽略”的未知项。
- 把旋转关键帧散落到多个网格对象，或让网格本身承担缩放动画，造成相位漂移、体检失败和后续导出难以维护。

## 验证方式

- 规格/装配表能逐项对应 Collection、`GRP_*` 根 Empty、网格、材质和 Action。
- `inspect_scene.py` 没有未解释的 FAIL；相交报告中的允许接触和结构性穿透有明确分类与处理记录。
- `capture_views.py` 的静态视角和多帧输出均已逐张审查；动画首尾连续、控制器正确、活动范围不出镜。
- 重新打开 `.blend` 后模块平移/恢复通过，且 `git diff --check`、项目校验和 Blender 工具 smoke 结果已记录。若本机未安装 Blender，必须把 runtime 标为 N/A，不把宿主脚本通过扩展为 Blender 运行时通过。
